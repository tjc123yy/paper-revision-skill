# 系统截图批量精修工具箱（Windows）

处理"导师要求改截图里的日期/姓名/账号/地址/加品牌标识"这类意见：
**不改截图内容与版式**，只在原图上做"局部擦除 + 同字体同色重绘"。

## 为什么不用别的办法

- 重新部署学生的系统再截图：多数任务拿不到源码/数据库，做不到。
- 用 HTML 重画界面：数据、按钮、照片都要重造，反而更容易被看出是假的。
- 直接用 Word/PowerPoint 贴文本框：改完是"补丁叠补丁"，字体字号对不上。

## 部件

| 文件 | 作用 |
|---|---|
| `ocr_winrt.ps1` | 调用 Windows 自带 WinRT OCR（zh-Hans-CN），把每张图识别成"行→词 + 像素框"的 JSON |
| `imglib.py` | 基础：暗色掩码、表格竖线/横线检测、列带与单元格定位、字形切分、模板匹配 |
| `imglib2.py` | 绘制：`paint_text`（按局部底色合成重绘）、`paint_lines`、表头定位、品牌条 |
| `edit_core.py` | 单项编辑：年份/月份替换、表单"标签右侧找值"、OCR 年份框偏移反推 |
| `edit_images_example.py` | 一份完整配置示例（按图给出要改的列、表单、手工框） |

## 用法

```powershell
# 1) 把 docx 里的图片导出到 media/
python -X utf8 -c "import zipfile,sys; sys.path.insert(0,r'..\..\scripts'); import docxlib as D; ..."
# 2) OCR（必须用 Windows PowerShell 5.1，pwsh 7 没有 WinRT 投影）
powershell -NoProfile -ExecutionPolicy Bypass -File .\ocr_winrt.ps1 -Dir .\media -Out .\ocr.json -Scale 2.0
# 3) 按图配置编辑规则，跑主程序
python -X utf8 .\edit_images.py
# 4) 重新 OCR，和原始 OCR 做差集，确认没有残留旧值
python -X utf8 .\ocr_check.py old=ocr.json new=ocr_new.json
```

## 关键实现要点（每条都踩过）

1. **必须做 alpha 合成，不能"只贴笔画"**：把文字画在白底画布上时，反锯齿边缘是"向白过渡"的灰度；
   直接把这些像素贴到灰底/条纹底上会出现刺眼的白边。正确做法：
   `cov = (255 - canvas) / (255 - 文字色明度)`，再 `dst = dst*(1-cov) + 文字色*cov`。
2. **裁剪画布要用画布坐标 20，不是 `20-bb[0]`**：文字是按 `(20-bb[0], 20-bb[1])` 画的，ink 左上角恒为 (20,20)。
   写错会让字形上下被切掉一半。
3. **擦除范围要比检测到的 bbox 大**：暗色阈值取到的 bbox 不含反锯齿边缘，只按 bbox 填充会在原位留下"残影"。
   实战取值：`grow_x=4, grow_y=6`（账号/姓名/地址），`grow_x=1, grow_y=4`（年份，横向会碰到相邻的"-"）。
4. **单元格定位的最小行暗点数要 ≥2**：截图里常有 1px 的竖向杂线，`rowdark>0` 会把整列粘成一个大格。
   同时列带要内缩 4px，避免把表格边框当成文字。
5. **表格没表头就不能"跳过第一格"**：有的截图是从第 1 行数据开始裁的。
   规则：只有当该列存在 OCR 识别到的表头文字框、且单元格与其重叠时才跳过。
6. **弹窗遮罩下的截图**（整幅背景是 127 灰）：暗色阈值要降到 ~115，并且要看"相对于背景"的对比，
   不能沿用 190。这类图最好整行重绘（`paint_lines`）而不是逐字替换。
7. **加高图片要同步改 docx 的显示尺寸**：在顶部补一条标题栏会使图片变高，
   要按 `cy_new = cy_old * h_new / h_old` 同时改 `wp:extent/@cy` 与 `a:ext/@cy`，
   这样每像素的显示比例不变、内容不被压扁。
8. **验证靠"重新 OCR + 差集"**：改完再 OCR 一遍，检查是否还有 `2023` / `ming` / `学生H` / `沧州` 等旧值、以及是否每张图都带上了品牌词。
   注意假阳性：账号 `2365000000000` 与数量 `120` 相连会出现 `1202365...`，里面含子串 `2023`。

## 已知限制

- 中文字体用 `msyh.ttc`（微软雅黑）。若原截图是别的字体，重绘的字会略有差异，缩放到论文里基本看不出。
- WinRT OCR 对"图+文"混排的表格行会漏字（有时只识别出一半单元格），
  所以定位要**以像素为主、OCR 为辅**：OCR 用来找表头与少量关键框，其余靠列带 + 文本行聚类。
- OCR 只在中文 Windows + 装了中文识别包时可用；`[Windows.Media.Ocr.OcrEngine]::AvailableRecognizerLanguages` 可先自检。
